How FastSpaceSwitch skips the slide

By Hadi Al-Musawi. Updated November 1, 2026.

FastSpaceSwitch sends a simulated trackpad swipe with very high speed and very little movement. This makes the macOS Dock switch Spaces without the usual slide animation.

From shortcut to desktop

  1. The app registers Ctrl+Left and Ctrl+Right through RegisterEventHotKey. It receives those shortcuts rather than watching every key.
  2. It reads the desktop list for the active display. If there is no desktop in that direction, it stops. If it cannot read the list, it still tries the switch.
  3. It sends three gesture events: began, changed, and ended. Speed is set to 2000.0 and progress to 0.000016. These are event values, not measured timings.
  4. The Dock handles the switch. The app waits in the background for the next shortcut.

What changes on your Mac?

The installer turns off the built-in left and right Space shortcuts so they do not compete with the app. It does not change Reduce Motion or real trackpad swipes. The uninstaller turns the two built-in shortcuts back on.

Why only macOS 26?

The app uses private event fields and window-server calls. Apple does not promise to keep these features unchanged. macOS 27 changed the swipe format, and this version does not include the new format.

Read the source and original work

The main implementation fits in one small file: main.m. The source also includes install and uninstall scripts.

The technique was adapted from InstantSpaceSwitcher by jurplel, under the MIT license.
