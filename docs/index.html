A small fix for a daily habit.

FastSpaceSwitch is a small Mac app that makes Ctrl+Left and Ctrl+Right switch between Spaces without the sliding animation. Spaces are the extra desktops you create in Mission Control.

It runs quietly in the background, with no Dock icon. It stops at the first and last desktop. Your normal trackpad swipes and other Mac animations stay the same.

How to switch Mac desktops instantly

Choose the download or build it yourself. Both need one permission in macOS.

Download the app

  1. Get the latest ZIP and open it.
  2. Open Terminal. Type cd , drag the extracted folder into the window, and press Return.
  3. Run ./install.sh --prebuilt.
  4. Allow FastSpaceSwitch in System Settings > Privacy & Security > Accessibility.
  5. Press Ctrl+Left or Ctrl+Right.

The download is not notarized by Apple. macOS may block its first launch. If you trust the project, use Privacy & Security > Open Anyway, then reopen it. Keep the extracted folder after installing.

Build from source

Requires Apple's Xcode Command Line Tools. If needed, install them with xcode-select --install.

git clone https://github.com/Hadi-Almusawi/fast-space-switch.git
cd fast-space-switch
./install.sh

The installer builds and opens the app, and gives Ctrl+Arrow to FastSpaceSwitch. Then allow Accessibility access.

After rebuilding, remove the old Accessibility entry and add the new app. To start it at login, add it to Login Items.

Common questions

How do I disable the macOS Spaces switching animation?

On macOS 26, run FastSpaceSwitch and press Ctrl+Left or Ctrl+Right. It skips the slide for those shortcuts, without turning off every animation on your Mac.

Does it change Reduce Motion or trackpad swipes?

No. It only registers the two Ctrl+Arrow shortcuts. Your trackpad and Reduce Motion settings stay the same.

Do I need to turn off SIP?

No. System Integrity Protection (SIP) can stay on.

Why does macOS ask for Accessibility access?

macOS needs this permission before the app can send the gesture that moves you to another desktop. The app only receives its two registered shortcuts. It does not record other keys, read your screen, or connect to the internet. Read the source code.

Why does nothing happen when I press Ctrl+Arrow?

Check that the app is running and allowed in Accessibility. After a rebuild, remove its old permission entry and add it again. Another app may be using the shortcut. At the first or last desktop, FastSpaceSwitch stops rather than wrapping around.

Does FastSpaceSwitch work on macOS 27?

No. macOS 27 uses a different gesture format. This release is for macOS 26. The InstantSpaceSwitcher project may offer other options.

How do I uninstall it?

Open Terminal in the install folder and run ./uninstall.sh. This stops the app, removes its local build, and restores the built-in shortcuts. If you added it to Login Items, remove it there too.

Get FastSpaceSwitch

Prefer Homebrew?

Use the project's own tap. Then allow Accessibility access. This version is for macOS 26.

brew tap Hadi-Almusawi/fast-space-switch https://github.com/Hadi-Almusawi/fast-space-switch.git
brew install --cask Hadi-Almusawi/fast-space-switch/fast-space-switch

The app runs from Homebrew's folder. To remove it and restore the built-in shortcuts, run brew uninstall --cask fast-space-switch.
