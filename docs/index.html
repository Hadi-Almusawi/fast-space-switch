What it does

FastSpaceSwitch runs quietly in the background. Ctrl+Left/Right switch desktops without the slide. Ctrl+Up/Down keep their normal Mac actions, with the Dock's window-view animation time set to zero. Desktop switching stops at the first and last desktop.

FAQ

Why does it need Accessibility access?

macOS requires it for the app's Ctrl+Left/Right desktop gesture. The app only receives those two shortcuts. It does not read your screen, record other keys, or connect to the internet. You can read the code.

Can it switch desktops instantly without that permission?

No. macOS requires Accessibility access for the synthetic gesture that skips the slide.

Does it change other Mac animations?

The Dock setting can also change how Mission Control and App Exposé open by trackpad. Reduce Motion and other Mac animations stay as they are. Uninstall restores your old Dock setting.

Does it need SIP turned off?

No. Keep System Integrity Protection on.

Get FastSpaceSwitch

Download the latest ZIP, open it, then run the included installer:

./install.sh --prebuilt

Allow FastSpaceSwitch in System Settings > Privacy & Security > Accessibility for instant Ctrl+Left/Right. Keep the extracted folder because the app runs from there.
