What is FastSpaceSwitch?

FastSpaceSwitch runs in the background and removes the slide animation when you switch desktops with Ctrl + ← or Ctrl + →. Switching stops at the first and last desktop.

Compatibility

macOS Tahoe 26✓ Supported
macOS 27✕ Not supported
macOS Sequoia 15 and earlier? Not tested

The installer runs only on macOS 26. The release includes versions for Apple Silicon and Intel Macs. Intel hardware has not been tested.

Frequently asked questions

Why does FastSpaceSwitch need Accessibility access?

macOS requires it for the app's Ctrl+Left/Right desktop gesture. The app only receives those two shortcuts. It does not read your screen, record other keys, or connect to the internet. You can read the code.

Can I switch desktops instantly without granting access?

No. macOS requires Accessibility access for the synthetic gesture that skips the slide.

Does it affect other macOS animations?

The Dock setting can also change how Mission Control and App Exposé open by trackpad. Reduce Motion and other Mac animations stay as they are. Uninstall restores your old Dock setting.

Do I need to disable System Integrity Protection (SIP)?

No. Keep System Integrity Protection on.

Install FastSpaceSwitch

  1. Download the ZIP. If it has not unzipped, double-click it in Downloads.
  2. Open Terminal and paste this line:
cd ~/Downloads/FastSpaceSwitch-1.2.0 && ./install.sh --prebuilt

If you saved the folder somewhere else, type cd in Terminal, drag the folder in, and press Return. Then run ./install.sh --prebuilt.

The installer copies the app to ~/Applications, opens it, and sets it to open when you log in. Allow FastSpaceSwitch in System Settings > Privacy & Security > Accessibility for instant Ctrl+Left/Right. macOS requires this access for the desktop switch gesture. You can then delete the downloaded folder.
